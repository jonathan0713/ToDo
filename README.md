<h1 align="center">TodoLauncher</h1>

<p align="center">
  Windows 側邊待辦面板，也是把每日工作環境一次準備好的快捷啟動器。
</p>

TodoLauncher 將「今天要做什麼」與「開始工作需要開什麼」放在同一張任務卡中。每個任務可以綁定一個或多個程式、捷徑或 URL；按下啟動後，所有項目會依序開啟，成功送出後自動標記完成。

面板平時收在螢幕側邊，也能從系統匣叫出。它適合每天固定會開啟一組工具，又不想反覆尋找捷徑或確認是否已經執行過的人。

## 特色

### 待辦與啟動整合

- 一個任務可以綁定多個啟動項目。
- 支援 EXE、COM、BAT、CMD、LNK 與 URL 捷徑。
- 所有啟動項目成功送出後，自動將任務標記完成。
- 每日任務隔天自動回到未完成；永久任務會保留完成狀態。
- 已完成任務仍可再次啟動，不需要先手動重設。

### 工作情境分組

- 自由新增、改名、刪除與排序群組。
- 每個群組可以設定圖示、強調色與折疊狀態。
- 任務卡可直接拖曳排序，或拖到另一個群組。
- 群組可提供「啟動未完成」按鈕，一次開啟尚未完成的任務。
- 智慧群組可依未完成、已完成、每日或永久任務自動分類。
- 手動分組永遠優先；自動規則依群組順序套用，不會重複顯示任務。

### 減少重複操作

- 「從執行中新增」可從目前有可見視窗的程式建立任務，自動帶入名稱與 EXE 路徑。
- 直接選取的 EXE／COM 可以設定「已開啟則切回」，避免重複開啟同一程式。
- 成功啟動後可以自動收合面板。
- 滑鼠位於面板任意位置時都能使用滾輪。
- 支援舒適／緊湊密度、不同面板寬度及卡片資訊顯示設定。

### Windows 桌面整合

- 螢幕側邊箭頭可快速展開或收合面板。
- 系統匣選單可顯示面板或完整退出程式。
- 單一實例保護，避免重複啟動多份 TodoLauncher。
- 使用原子寫入保存資料；損毀的資料檔會先備份再回復空白資料。

## 快速開始

### 從原始碼執行

需求：Windows 10／11、Python 3.10 以上版本。

```powershell
git clone https://github.com/jonathan0713/ToDo.git
cd ToDo
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python todo.py
```

程式啟動後會縮在螢幕右側。按側邊箭頭展開面板，再建立第一個任務。

### 封裝成獨立 EXE

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller --clean --noconfirm `
  --workpath .pyinstaller-build `
  --distpath dist `
  todo.spec
```

完成後的執行檔位於 `dist\todo.exe`。它已包含 Python 執行環境，目標電腦不需要另外安裝 Python。

> 建議使用全新的虛擬環境封裝，避免將 Conda base 或其他環境中的無關套件一併收進 EXE。若 PyInstaller 顯示 Tkinter 被排除，請先確認 `.venv\Scripts\python.exe -m tkinter` 能正常開啟測試視窗。

## 基本操作

| 操作 | 行為 |
| --- | --- |
| `Insert` | 新增任務 |
| `Enter` | 啟動目前選取的任務 |
| 雙擊任務卡 | 啟動該任務 |
| `Space` | 切換完成狀態 |
| `Delete` | 刪除選取的任務，執行前會再次確認 |
| `↑`／`↓` | 切換目前選取的任務 |
| `Esc` | 收合面板 |
| 任務卡左側把手 | 拖曳排序或移動至其他群組 |
| 側邊箭頭 | 展開或收合面板 |
| 側邊箭頭右鍵／系統匣 | 顯示面板或完整退出程式 |

主畫面的 `×` 只會收合面板，不會結束背景程序。若要完整退出，請使用系統匣或側邊箭頭的右鍵選單。

## 任務與群組

### 完成模式

| 模式 | 行為 |
| --- | --- |
| 每日重置 | 僅將今天的完成紀錄視為完成，隔天自動恢復 |
| 永久保留 | 完成後持續保留，直到使用者手動切換狀態 |

### 智慧群組

要讓任務接受智慧群組規則，請在任務的「所屬群組」選擇「依規則自動分類」。設定頁中位置較高、且第一個符合條件的群組會接收該任務。

手動指定到某個群組的任務不受智慧規則影響。

### 已開啟則切回

此選項會搜尋與目標執行檔路徑相同的可見視窗：找到時將視窗還原並切到前景，找不到時才建立新程序。

目前只支援直接選取的 `.exe` 與 `.com`。捷徑與 URL 無法穩定判斷最終目標，因此不提供這個選項。

## 資料儲存

正式使用的資料位於：

```text
%LOCALAPPDATA%\TodoLauncher\tasks.json
```

- Repo 內的 `tasks.json` 已被 Git 忽略，不會意外提交個人任務。
- 若舊版本曾將 `tasks.json` 放在程式目錄，首次啟動新版時會將它複製到使用者資料目錄。
- 後續只會讀寫 `%LOCALAPPDATA%` 中的資料。
- `tasks.example.json` 是可公開的格式範例，不會被程式當作個人資料使用。
- 無法解析的資料檔會備份為 `tasks.json.corrupt-時間.bak`。

## 已知限制

- 僅支援 Windows。
- 「從執行中新增」只列出有可見視窗、且 TodoLauncher 有權取得執行檔路徑的程式；部分系統或系統管理員權限程式可能不會出現。
- 啟動成功代表 Windows 已接受啟動要求，不代表目標程式已完成載入或內部工作已成功。
- LNK 與 URL 可以啟動，但不支援額外參數或「已開啟則切回」。

## 開發與測試

執行完整測試：

```powershell
python -m unittest discover -s tests -v
```

目前測試涵蓋資料格式正規化、舊版遷移、每日／永久完成狀態、安全啟動、視窗切回、批次啟動、拖曳排序、智慧群組與滾輪互動等核心邏輯。

### 專案結構

| 路徑 | 用途 |
| --- | --- |
| `todo.py` | Tkinter 主介面、任務互動、群組管理與系統匣整合 |
| `task_store.py` | 資料正規化、版本遷移、完成狀態與原子寫入 |
| `launcher.py` | 安全啟動、執行中程式列舉與既有視窗切回 |
| `tasks.example.json` | 資料格式範例 |
| `tests/` | 單元測試 |
| `todo.spec` | PyInstaller 封裝設定 |

## 設計原則

TodoLauncher 將高頻操作放在任務卡與主畫面，低頻操作收進 `⋯` 選單與設定頁；顏色只用於主要操作、狀態回饋和群組識別。介面採用 Windows 的繁體中文字體，並維持足夠的文字對比，讓面板可以快速掃讀而不搶走正在進行工作的注意力。
